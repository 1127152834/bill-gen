# 通用：不管哪家银行都成立的填写规矩

先读这一份，再读具体银行的 reference。这份讲「所有表单共有的字段语义」，具体写法以各银行 reference 为准。

## 1. 身份字段

| 字段类型 | 怎么填 | 反例 |
| --- | --- | --- |
| 人名 | 名 + 姓，首字母大写（`Maya Okafor`）；需要全大写的字段（`customer_lines`、`owner_names`）按字段要求给大写 | `John Doe`、`USER NAME`、`your name` |
| 地址 | 门牌 + 街名（可带 `Apt 12`）；第二行 `城市 ST ZIP`，州用两位缩写 | `123 Main St`、`Anytown, USA` |
| 公司 | 真实质感的实体名（`Okafor Design Studio LLC`），不要 `Example Corp` | `ACME Inc`、`Demo Company` |
| 账号 | 10–17 位数字；某些版式带空格分段（`4107 3721 1347`） | `0000000000`、`1234567890` |
| 路由号 | 9 位且过 ABA 校验（第 9 位是前 8 位的校验位） | `000000000` |
| 卡尾号 | 4 位数字，来源是账本的 `accountLast4` | 全 0、`1234` 当万能值 |

## 2. 金额

- 表单里金额是**字符串**：`"1284.73"`、`"-314.24"`；**不要** `"$1,284.73"`（Boa/WF 的少数展示字段例外，reference 会写明）。
- 分表合计要用同一套符号口径：BoA 的 `checks` 是 `"0.00"`，不要写 `"-0.00"`。
- 期初 + 贷 − 借 必须等于期末；差额不是「四舍五入」，是错。

## 3. 日期

| 形态 | 例 | 常用在 |
| --- | --- | --- |
| `MM/DD` | `01/04` | Chase、Wells Fargo 流水 |
| `MM/DD/YYYY` | `10/31/2026` | Amex 表头 |
| `Mon D` | `Jan 4` | U.S. Bank 流水 |
| `Mon DD, YYYY` | `Oct 01, 2026` | Mercury 表头 |
| `Month D, YYYY` | `October 30, 2026` | WF 出件日、BoA 摘要 |
| `MM/DD/YYYY - MM/DD/YYYY` | `10/01/2026 - 10/31/2026` | SoFi 账期 |

账期跨度 28–31 天；出件日 = 期末 + 1~3 个工作日，不是期末当天。

## 4. 流水行

- 行序按日期升序；同日按入账先后，不要按金额排。
- 商户名全大写（`WHOLE FOODS MKT 105`），行文由银行决定（见各 reference）。
- 描述超宽**硬切**，不印 `…`。
- 同一商户跨月保持同一写法，不要这月 `WHOLE FOODS` 下月 `WHOLEFDS`。

## 5. 五类流水的语义

| 类型 | 含义 | 出现形式 |
| --- | --- | --- |
| `ACH` | 工资、房租、水电、保险等自动转账 | 常带公司名 + 参考号；借记/贷记要分清 |
| `POS` | 借记卡消费 | 商户 + 城市州（+ 部分银行的卡尾号） |
| `ATM` | 取现 | 终端号 + 城市；常伴 `ATM SURCHARGE` |
| `CHECK` | 纸质支票 | 支票号，按时间递增 |
| `ZELLE` | 个人转账 | 对方姓名 + 确认号 |
| `FEE` / `INTEREST` | 银行费用 / 利息 | 期末附近，金额小 |

## 6. 一律不许出现

`SAMPLE`、`EXAMPLE`、`DEMO`、`DUMMY`、`TEST DATA`、`LOREM IPSUM`、`JOHN DOE`、`PLACEHOLDER`、
`0` 开头的 9 位以上账号、全零路由号、`…`、`$` 与千分位混进纯数字字段、`N/A`、`-`、空列。

## 7. 结构一致性

- 有列就要有值：`CATEGORY`、`TYPE`、`Ref Number`、`End of Day Balance`、`ID` 这类列留空就是穿帮。
- 摘要区与明细区必须对得上：summary 的笔数、合计要与明细行数、金额之和一致。
- 页数与内容匹配：20 行流水不应该摊成 6 页，2 行流水也不应该挤在第 5 页。
