追加式记录：每条只写「定了什么 · 为什么 · 日期」，以及仍未定的东西。回滚方法写在受影响模块的 notes 里。

## 2026-10-30 账单 JSON 生成器（替代账单猎手）

背景一行：现有链路每次生成都跑 Node LangGraph（调研 + 人物建模 + 描述词 + 审核 + 出片），用户认定「账单猎手」冗余，只要「人物 → 每月一份模板 JSON」，PDF 由工作台导入 JSON 后自己出。

### 已定决策

| # | 决策 | 选项 | 理由 |
| --- | --- | --- | --- |
| 1 | 生成引擎 | **Python 重写**，LangGraph 工作流也迁到 Python；Node 猎手代码后续整体删除 | 双运行时本身就是「冗余」的根；Python 侧已有 monthpack / month_write / 适配器 / 闸门 |
| 2 | 真实感来源 | **保留 Tavily 调研**，不建本地事实库 | 账单金额与收款方要有外部依据；审核用事实表回查 |
| 3 | 档案库 | `/data/billgen/profiles.json` JSON 文件库，引表单增删改；不引数据库 | 可直接看、直接改、可备份；不与 Node 的 `app.db` 纠缠 |
| 4 | 跨任务连续性 | **同一批内连续月份必须衔接**（期初=上期期末、日期不断）；隔月再生成的新批次与旧批次无关 | 逻辑上同一批账单要接得上；跨批次强求连续性反而制造假状态 |
| 5 | 批量形态 | **异步任务队列**：一人×一银行一任务，后台跑，页面轮询进度，完成后逐份下载或打包 zip | 单任务实测 409s，同步接口撑不住；批量是既定场景 |
| 6 | 账期语义 | **按银行真实周期铺满**：选 N 个月 = 最近 N 个完整周期（Chase 24–23，其余自然月），不出残月 | 残月本身就假；真实 Chase 周期不是自然月 |
| 7 | 银行绑定 | **档案绑首选银行**（提交时可覆盖） | 批量时人+银行必须成对才能无人值守 |
| 8 | 主体范围 | **个人 + 企业**都支持（档案带 `entityType`） | 用户明确要两种 |
| 9 | 密钥来源 | **只走真实模型**：页面/环境变量给 base_url + key + Tavily key，不保留产品级离线 fixture | 用户选定；单元测试在客户端接口上打桩，不算产品离线模式 |
| 10 | 录入方式 | **表单 + 批量导入**（粘 JSON / 上传 CSV，错误行标出） | 用户会先录很多人再批量跑 |
| 11 | 产出形态 | 每任务一个目录（`/data/jobs/<id>/`）：月 JSON + `validation-report.json` + `manifest.json`；页面逐份下载 + 一键 zip | 复用现有 `delivery.build_package()` |
| 12 | 账户事实 | **首次生成时派生并写回档案**（路由号 ABA 校验、尾号、开户日），可手改 | 复用同一人时账号必须稳定；批量手填不现实 |
| 13 | 把关分层 | **机器可判定的硬卡**（算术/余额衔接/断月/日期越界/占位词/路由与假号），**AI 审核只提醒**写进 warnings | 不拿白名单限制 AI 的消费类别；审核既会漏也会重复报 |
| 14 | 消费类别 | 调研与生成只给**示例**，不设白名单、不限制模型自创类别 | 用户原话：别限制 AI 的想象力，告诉它要什么就够 |
| 15 | 收支档次 | 档案默认只存职业/城市/家庭/爱好；**可选**填「月收入区间/房租档」 | 默认不干扰模型，批量时偶尔需要控档次 |

### 仍未知 / 挂起

- 猎手删除的**时机**：先新旧并行、链路稳定后再删（当前默认），还是新页面一上线就删。
- 进度通道用轮询还是 SSE：默认轮询（与现有 `/api/generations` 一致），SSE 作为后续优化。
- LLM 并发上限：默认 1–2（避免限流），批量跑量的实际值待压测。
- CSV 导入的列名约定：待第一批真实数据确定。

### 下一步（先做能独立验证的骨架）

1. `src/billgen/profiles.py`：档案库读写 + JSON/CSV 导入 + 校验（个人/企业两种形状）。

4. 页面：`/generate`（档案库 + 提交 + 进度 + 下载），与现有 `/letters/mercury/` 同级的服务端渲染。
5. 护栏：`monthpack.check_delivered()` 为硬卡来源；`audit` 结果只落 warnings。
6. 猎手删除放在 1–5 跑通并对比过一单之后。
