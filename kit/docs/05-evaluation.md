# 怎么验收「像不像真的」（别再凭感觉）

五道门槛，全过才算能用。**每一条都要能被脚本重复跑出来**。

## 门槛 1：闭合率 100%（硬门槛）

- 期初 + Σ流水 = 期末，逐月成立；
- 逐行余额链连续；
- 跨月：上月末 = 下月初（多个月一起生成时）。

脚本判据：任意一行不成立即失败。**这条不过，后面都不用看。**

## 门槛 2：格式 lint 0 问题

```bash
python3 kit/tools/statement_lint.py --contract contracts/chase-personal.json --data month.json
```

覆盖：类型枚举、卡行城市/卡尾、描述符长度、金额精度、禁词、前导空格、必填字面量。

## 门槛 3：分布回归（p > 0.01）

对每个类目，把产出的金额分布与 `distributions.json` 比：

- 金额：KS 检验，p > 0.01（拒绝「同分布」才算失败）；
- 笔数：落在 `per_month` 区间；
- 间隔：日期间隔的均值/方差在参考区间内；
- 星期：周末消费占比与参考差异 < 15 个百分点。

**别用「均值差不多」当通过**——均值一样、形状完全不同是最常见的假。

## 门槛 4：地理/日历一致性

- 商户、公用事业、连锁品牌与档案所在城市/州一致；
- 节日消费落在节日**前后 3 天内**（感恩节采购在节前 1–3 天，黑五在节后当天）；
- 州域品牌不出界（加州不出现 `WHATABURGER`）。

## 门槛 5：盲测辨识率 ≤ 65%（最重要，也最容易被跳过）

做法（半小时能跑完）：

1. 取 **6 份真实账单**（不同银行）与 **6 份你的产出**，混在一起，只保留流水区（裁掉抬头/logo，避免靠 logo 猜）；
2. 找 **5 个没参与开发的人**（同事、朋友都行），每人独立判断「哪份是假的」，并写下理由；
3. 统计：正确率 = 判对数 / 60；把理由归类（金额不自然 / 商户奇怪 / 日期怪 / 排版怪 / 说不出但就是假）；
4. **通过线：≤65%**。当前如果你的产出是 90%，说明问题非常集中，通常前三条理由就占掉 70%。

> 这个仓库目前的真实状态：**没测过**。没有基线数字之前，任何「已经很真了」都是自我感觉。

## 反例库（每次抓到假就加一条）

把盲测里被指出的具体行贴进 `docs/false-positives.md`，一行一条，格式：

```
[2026-10] "SUBWAY -222.55"  真实 Subway 单笔中位 $12，$222 是团餐量级 → 已加 dining 上限 $85
[2026-10] "TRADER JOE'S RALPHS KROGER"  两家品牌粘连 → 连锁替换改成整条重写
```

三个月后这份文件就是你的护城河。
